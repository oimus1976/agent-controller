# Governance for workers

These documents hold the rules that every worker follows. Root [`AGENTS.md`](../../AGENTS.md) is the short entry point and links here.

| Document | Purpose |
|---|---|
| [`rules.md`](rules.md) | The standing rules, each linked to its owning Issue or ADR |
| [`checkpoint-template.md`](checkpoint-template.md) | The handoff checkpoint to post on the workstream Issue |
| [`review-record.md`](review-record.md) | How to record review independence (L0–L3) in a PR |
| [`post-merge-closeout.md`](post-merge-closeout.md) | The local closeout procedure after a human merge |

Standing architecture decisions:

- [ADR #12](https://github.com/oimus1976/agent-controller/issues/12): provider-neutral, reuse-first control plane.
- [ADR #90](https://github.com/oimus1976/agent-controller/issues/90): human-final LEVEL 3 authority.
- [ADR #179](https://github.com/oimus1976/agent-controller/issues/179): specification-driven development with layered assurance.
- [ADR #199](https://github.com/oimus1976/agent-controller/issues/199): independent implementation and fresh-head review.
